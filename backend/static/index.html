07 // FREQUENTLY ASKED QUESTIONS

EVERYTHING YOU NEED TO KNOW ABOUT ECHO

Do I need expensive specialty microphone hardware?

No. ECHO was engineered to operate on commodity hardware using standard built-in microphones found on modern smartphones, laptops, tablets, and desktop webcams via standard 16kHz audio streams.

Will watching television or action movies trigger alarms?

No. ECHO's two-pass architecture incorporates an automatic media-playback acoustic discriminator that checks for continuous spectral dispersion characteristic of cinema soundtracks, actively suppressing false alarms.

What if an alert is triggered by accident?

ECHO provides a mandatory 12-second abort countdown window with an audio alert and a high-visibility "I'M SAFE" button. Tapping this cancels the escalation immediately before voice calls are made.

Can I test the system without actually alerting authorities?

Yes. The built-in Demo Lab allows you to inject prepared sound signatures (gunshot, scream, fireworks, siren) into the detection pipeline safely. Rehearsal mode simulates carrier delivery with zero actual calls placed.
